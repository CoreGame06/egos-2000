# Apps 目录说明

`app.h` 和 `app.s` 是程序共用的代码。`system/` 下的四个服务都运行在用户态。

| 文件 | 作用 |
| --- | --- |
| [app.h](app.h) | 提供 Earth 和 Grass 的接口指针，以及 Shell 和 `cd` 共享的当前目录编号和路径。 |
| [app.s](app.s) | 进程第一次运行时的入口。取出参数个数，设置栈指针，再调用 `main()`。`main()` 返回后调用 `exit()` 请求退出。 |
| [sys_proc.c](system/sys_proc.c) | 第一个系统进程。放行其它核心，依次启动终端、文件和 Shell 服务，之后处理进程创建、退出和睡眠请求。 |
| [sys_terminal.c](system/sys_terminal.c) | 处理终端输入输出请求。收到输入请求就从串口读一行并回复，收到输出请求就把文字写到串口。 |
| [sys_file.c](system/sys_file.c) | 处理文件块的读写请求。文件系统根据文件编号和文件内块号找到对应的磁盘数据，服务再把操作结果发回请求者。 |
| [sys_shell.c](system/sys_shell.c) | 显示提示符、读取并解析命令。内置命令直接处理，其它命令交给 `sys_proc` 创建进程。前台命令还要等进程退出。 |

Grass 先启动 `sys_proc`。`sys_proc` 收到终端服务的就绪消息后启动文件服务，再等文件服务就绪，最后启动 Shell。

Shell 负责理解命令，终端服务负责字符输入输出。在本项目中，Shell 自己读命令和显示提示符时直接用串口。普通用户程序通过消息请求终端服务读写串口。
