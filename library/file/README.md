# File 目录说明

这个目录实现文件系统。上层用 **inode 号**指定文件，用 **文件内块号**指定要读写的位置。文件系统负责找到对应的分区块，每块 512 字节。

| 文件 | 作用 |
| --- | --- |
| [disk.h](disk.h) | 定义块大小，以及内核、系统服务和文件系统在磁盘镜像中的位置。 |
| [inode.h](inode.h) | 定义统一的块读写接口。文件系统用它访问分区，`sys_file` 也用它访问文件。 |
| [file0.c](file0.c) | 默认文件系统 `mydisk`（`FILESYS=0`）。inode 记录文件长度和首块，FAT 表记录每一块后面接哪一块。写入需要扩容时从空闲链取块，缩小时把多余的块还回去。 |
| [file1.h](file1.h) | 定义备用文件系统 `treedisk` 的磁盘结构，包括 inode、树索引和空闲块表。 |
| [file1.c](file1.c) | 实现 `treedisk`（`FILESYS=1`），从 inode 指向的根块出发，沿索引树查找文件数据。 |

## 以 cat README 为例

1. `dir_lookup()` 从当前目录的内容中查到 `README` 对应的 inode 号。镜像里的初始目录为它登记的是 5。见 [mkfs.c](../../tools/mkfs.c)。
2. `cat` 通过 `file_read(5, 0, buf)` 请求读取这个文件的第 0 块。`sys_file` 调用 `mydisk_read()`，从 inode 找到首个数据块。
3. `mydisk_read()` 找到的是**分区内块号**。`sys_file` 的底层接口再加上分区起始块号 `4096`，把**整盘块号**交给 Earth 的磁盘驱动。

例如一个文件的块链是 `35 → 40 → 52`，读取文件内第 `2` 块时，从首块沿 FAT 走两步，读到分区块 `52`，对应整盘块 `4148`。
