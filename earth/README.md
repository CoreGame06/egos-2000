# Earth 目录说明

Earth 负责启动时的底层初始化，并提供内存、定时器和设备操作接口，供 Grass 等部分调用。

| 文件 | 主要作用 |
| --- | --- |
| [boot.s](boot.s) | 最早执行的汇编入口。各核心竞争启动锁，获得锁后设置栈指针，再调用 C 函数 `boot()`。 |
| [boot.c](boot.c) | 组织启动初始化。首个核心初始化串口、磁盘、内存管理、中断、显示和网卡，再调用 `grass_entry()`；其它核心配置自己的页表和中断等状态，然后等待调度。 |
| [cpu_intr.c](cpu_intr.c) | 配置中断和定时器：指定中断处理入口、允许接收哪些中断、读取当前时间、设置下一次时钟中断。实际的中断处理和进程调度在 Grass 中。 |
| [cpu_mmu.c](cpu_mmu.c) | 管理物理页的分配与回收；为进程建立页表、添加地址映射、查询虚拟地址对应的物理地址，以及切换当前核心的页表、刷新 TLB。 |
| [dev_tty.c](dev_tty.c) | 串口字符输入输出：检查是否有输入、读取一个字符、输出一个字符，并将这些函数登记到 Earth 接口。 |
| [dev_disk.c](dev_disk.c) | 初始化 SD 卡控制器，按块读写磁盘，每块 512 字节。使用 DMA 在设备与中转缓冲区之间搬运数据，CPU 轮询设备状态；也包含启动时的读写自测。 |

启动主线：`boot.s` → `boot.c` → 各模块初始化 → `grass_entry()`。

例如，`disk_init()` 把读接口登记为 `earth->disk_read`，上层调用这个接口，就会执行 `dev_disk.c` 中的 `disk_read()`。
